# Outputs

Ce dossier regroupe les artefacts generes:

- `checkpoints/`: copie organisee des checkpoints existants.
- `predictions/`: copie organisee des predictions existantes.
- `comparisons/`: figures, CSV et NetCDF de comparaison.
- `masks/`: sorties des analyses d'evenements extremes.
- `figures/`: figures globales.
- `archives/`: fichiers compresses telecharges ou exportes.

Important: les checkpoints originaux restent aussi dans chaque dossier de
modele (`DDPM/checkpoints`, `DeepSD/checkpoints`, etc.) pour ne pas casser les
scripts deja utilises.
