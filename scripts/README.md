# Scripts

Les scripts Python principaux restent a la racine du projet pour garder les
anciennes commandes fonctionnelles, par exemple:

```bash
python make_to_predict.py --date 2025-01-03
python compare_all.py
python results_extreme90.py --use-saved-predictions
```

Ce dossier est reserve aux nouveaux scripts d'automatisation ou aux wrappers
de lancement.
